# Hardware record

Equipment includes a Raspberry Pi controller, Adafruit Perma-Proto HAT, DS18B20 temperature sensor, optical level sensor, relay-driven power strip, and separate 5V/12V supplies following troubleshooting of a buck-converter issue.

**Do not treat this as an electrical wiring guide.** Schematics, photographs, and any current modifications must be checked before operating AC-powered devices. The project contains component/cost tables and links to original reef-pi / Adafruit tutorials.
